# 🖼️ Image Gallery

## Project Description
The Image Gallery is a responsive web application developed using HTML, CSS, and JavaScript. It displays images in an attractive grid layout with interactive features and smooth animations.

Users can view images, navigate between images, and filter them based on different categories.

## Technologies Used
- HTML5 – Structure of the webpage.
- CSS3 – Styling, layout, hover effects, and responsive design.
- JavaScript – Image navigation, lightbox functionality, and category filtering.

## Features
- Responsive image gallery layout.
- Next and Previous image navigation.
- Lightbox image viewing.
- Category filters:
  - All
  - Nature
  - Animals
  - Flowers
- Smooth hover effects and transitions.
- Mobile-friendly design.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Click on any image to view it in lightbox mode.
5. Use Next and Previous buttons to navigate between images.
6. Select category buttons to filter images.
